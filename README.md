# Portfolio – André Ghiringhelli

A professional portfolio built using pure HTML, CSS, and JavaScript — fully responsive, multilingual, and featuring light/dark theme support.

This project showcases my background, technical skills, professional experience and real business results delivered through process analysis, automation, development and practical digital solutions.

🔗 https://andre-myportifolio.vercel.app

## 📌 About This Project

This repository contains the source code of my professional portfolio, designed to be simple, fast and entirely maintained using native JavaScript without frameworks.

It includes:

- **Multilingual system** with support for PT-BR, PT-PT, EN and ES
- **Dark/Light theme**, persisted via LocalStorage
- **Responsive mobile menu** with animated hamburger icon
- **Automatic slideshows** inside study case cards
- **Process Results section** showcasing real operational metrics and performance indicators
- **Study case cards** created for learning, practice and technical development
- **Modular structure** separating:
  - Static HTML
  - A single CSS file powering the entire website
  - JavaScript split into menu logic, internationalization and main functionality

It follows a lightweight technical structure:

- Pure **HTML**, **CSS**, and **JavaScript**
- No frameworks
- Clean, modular code
- Fully responsive
- Multilingual content managed through translation tables

## 🧩 Features

### ✔️ **Responsive Design**
The portfolio adapts smoothly across desktop, tablet and mobile resolutions.

### ✔️ **Internationalization**
The website supports multiple languages through a JavaScript translation file.

Available languages:

- PT-BR
- PT-PT
- EN
- ES

### ✔️ **Dark/Light Theme**
Theme switching is handled with JavaScript and persisted in LocalStorage.

### ✔️ **Animated Mobile Menu**
The mobile menu includes:

- Hamburger animation
- Auto-close after link selection
- Responsive behavior on screen resize

### ✔️ **Automatic Study Case Sliders**
Each study case card includes image sliders with automatic transitions.

### ✔️ **Clickable Study Cards**
Each case study card works as a full clickable area, making the navigation cleaner and removing the need for additional buttons inside the cards.

### ✔️ **Process Metrics Showcase**
The Process Results section highlights real performance indicators from professional experience.

### ✔️ **Case Study Presentation**
The portfolio organizes personal and learning-based projects as study cases, using visual cards, automatic sliders and direct links to the live versions.

### ✔️ **Consistent Visual Language**
The interface uses dark/light contrast, clean spacing, responsive grids and modern card-based sections.
